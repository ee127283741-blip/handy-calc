# AI Founder Atlas

AI startup case library (https://ai-founder-atlas.pages.dev): real AI startups with sourced, dated revenue numbers, by industry and product type. Built with Astro (SSG), TypeScript and plain CSS.

```bash
npm ci && npm test && npm run build && npm run preview
```

| File | What it covers |
|---|---|
| `SPEC.md` | Site spec: constraints, stack, routes, case page, technical SEO, ads, legacy redirects (Traditional Chinese) |
| `PUBLISHING.md` | How to research, write, update and publish a case, plus SEO/GEO/AEO writing knowledge (Traditional Chinese) |
| `IMAGE_SOURCES.md` | Image and font sources and licenses |
| `src/content/cases/` | One Markdown file per case |
| `.env.example` | Environment variables |

The repository is named `handy-calc` because the project started as a calculator site; every old URL 301-redirects (see `public/_redirects`).
