# AI Founder Atlas

AI startup case library (https://ai-founder-atlas.pages.dev) built with Astro (SSG), TypeScript and plain CSS. See `SPEC.md` for the spec and `PUBLISHING.md` (Traditional Chinese) for the publishing workflow and the case writing standard.

```bash
npm ci && npm test && npm run build && npm run preview
```

Env vars: see `.env.example`.
