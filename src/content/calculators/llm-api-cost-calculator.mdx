## Worked example: a support-reply assistant

A small business drafts 100 customer replies a day, every day. Each request sends about 1,000 input tokens (instructions plus the customer's email) and gets back about 500 output tokens.

1. Cost per request on GPT-6.1 Sol: 1,000 × $2 / 1,000,000 + 500 × $10 / 1,000,000 = $0.002 + $0.005 = **$0.007**.
2. Requests per month: 100 × 30 = 3,000.
3. Monthly cost: 3,000 × $0.007 = **$21.00**.
4. The same usage costs $1.05 a month on GPT-6 Luna or Claude Haiku 5.5, $4.65 on Gemini 3.5 Flash-Lite and $105 on GPT-6 Astra or Claude Fable 5.1.
5. If you only know words: 750 words ÷ 0.75 words per token = 1,000 tokens.

## How the cost calculation works

<code class="formula">cost per request = (input tokens × input $/1M + output tokens × output $/1M) ÷ 1,000,000</code>

<code class="formula">monthly cost = cost per request × requests per day × days per month</code>

- **Tokens from words:** tokens = words ÷ words per token (default 0.75).
- **Scheduled prices:** where a provider has announced a change, the price in effect on today's date is used and the upcoming change is listed under the table.
- **Long prompts:** Claude Haiku 5.5 costs $0.50 input / $2.50 output per 1M tokens when a prompt exceeds 100K tokens; the calculator switches automatically. OpenAI prices shown are for prompts up to 272K input tokens.
- **Limitations:** standard tier only; no caching, batch, tool-call, image, audio or search charges; taxes excluded.
