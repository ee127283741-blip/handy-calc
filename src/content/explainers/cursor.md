Cursor is the tool behind several stories in this library. Hasaam Bhatti found it on Twitter and built [Launch Fast](/cases/launch-fast/) in it with no coding background, and the two founders of [My AskAI](/cases/my-askai/) list it among their internal tools. In 2026 Cursor's own story changed sharply.

## What is Cursor AI?

Cursor is a code editor with AI built in. Instead of adding an assistant to a separate editor, you write code, chat with AI and run agents on your project in one app. That makes it popular with professional developers and with non-programmers who describe what they want and let the agent write it.

## Who owns Cursor now?

Cursor was built by Anysphere. On 16 June 2026, CNBC reported that SpaceX would acquire Cursor for $60 billion worth of stock in an all-stock deal, expected to close in the third quarter of 2026 subject to regulatory approvals ([CNBC](https://www.cnbc.com/2026/06/16/spacex-spcx-cursor-acquisition-ipo.html)). The same report noted that Cursor had said in November 2025 that it had crossed $1 billion in annualized revenue.

The change shows in the product. Cursor's plans now share a usage pool with xAI's [Grok](/what-is/grok/) models, and the free plan even lists posting, replying and following on X.

## How much does Cursor cost?

| Plan | Price | What it includes |
|---|---|---|
| Free | $0 | Limited agent and chat requests |
| Plus | $8/mo | Shared AI usage pool for Cursor and Grok, Grok models, Grok API access |
| Premium | $30/mo | 4x Plus usage, latest Grok models, cloud agents, code hosting, AI code reviews |
| Super | $100/mo | 15x Plus usage and priority access at peak times |
| Ultra | $200/mo | 50x Plus usage and earliest access to new products |
| Teams | From $30/user/mo | Pooled usage, central billing, analytics, SSO |
| Source | [Cursor pricing](https://cursor.com/pricing), checked 2 November 2026 | Third-party models billed separately |

## How does Cursor compare with Claude Code and Codex?

[Claude Code](/what-is/claude-code/) and [Codex](/what-is/codex/) are coding agents you bring to your own tools, and both work in the terminal and the cloud. Cursor is the editor itself. They are not exclusive: Claude Code's VS Code extension installs in Cursor too. Launch Fast's founder started in Cursor and later moved to running Codex and Claude Code side by side.

## Who should use Cursor?

Developers who want AI inside their editor, and beginners who want one app to build in. If you rely on Claude or GPT models, check how Cursor bills third-party usage on your plan, since its included pool is built around Grok.
