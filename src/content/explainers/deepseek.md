DeepSeek is the AI lab many developers look to when they want strong models they can run or inspect themselves. It also matters for agents: open-source tools like [Hermes Agent](/what-is/hermes-agent/) let you plug in whichever model provider you prefer. Here is what DeepSeek offers.

## What is DeepSeek?

DeepSeek is an AI lab that builds large language models and publishes its releases. Its website lists a line of models from DeepSeek V3 and R1 through V3.1, V3.2, V4 and V4.1, with a banner noting that DeepSeek V4.1 Flash was updated to version V4.1-Flash-1017 ([DeepSeek](https://www.deepseek.com/en), checked 2 November 2026).

## Where can you use DeepSeek?

| Product | What it is |
|---|---|
| DeepSeek Web | Chat in the browser at chat.deepseek.com |
| DeepSeek App | Mobile app |
| API platform | Developer API; now supports web search and fetch |
| DeepSeek Harness | Agent tool and desktop app ("Everything is a Plugin") |
| Source | [DeepSeek](https://www.deepseek.com/en) |

## What does DeepSeek publish on GitHub?

DeepSeek's GitHub organisation had about 113,000 followers when we checked ([GitHub](https://github.com/deepseek-ai)). Its pinned projects include DeepSeek Harness, MIT-licensed with about 269,000 stars, and DeepInfer, an Apache-2.0 inference framework for DeepSeek models with about 25,000 stars. It also publishes lower-level performance libraries such as FlashMLA, DeepEP and DeepGEMM under the MIT license.

## How much does DeepSeek cost?

The web chat and app are free to use, and the API is billed by usage; DeepSeek links to a separate API pricing page and says the V4.1 Flash update lets tasks finish "at lower cost and faster speed" ([DeepSeek](https://www.deepseek.com/en)). Check the API pricing page for current rates.

## How does DeepSeek compare with Claude and ChatGPT?

[Claude](/what-is/claude-ai/) and [ChatGPT](/what-is/chatgpt/) are polished assistants from companies that keep their main models closed. DeepSeek's appeal for builders is openness: much of its tooling is published under permissive licenses, and its API is a common choice inside agent frameworks. The trade-off is that you do more of the setup yourself.
