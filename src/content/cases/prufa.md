A deploy that breaks checkout rarely throws an alert. The first sign is often a drop in sales or an angry support email. Prufa sells a guard against that. The US company, founded in August 2025, had $3,962 in lifetime revenue by November 2026, and $2,846 of it came in the last 30 days ([verified, TrustMRR](https://trustmrr.com/startup/prufa)). Its MRR, though, was just $29, which makes it an odd and instructive case.

## What does Prufa test after every deploy?

Prufa runs your signup, login and checkout flows in a real browser after every deploy and machine-verifies the result ([founder-reported, TrustMRR](https://trustmrr.com/startup/prufa)). An LLM-backed agent navigates the app like a user; plain code checks each outcome, and any LLM judgment is labelled advisory.

> "Free 60-second audit: paste a URL, no signup." — Prufa company description ([founder-reported, TrustMRR](https://trustmrr.com/startup/prufa))

Humans get a dashboard, reports and Slack alerts. AI agents get a CLI, a versioned API, an MCP server and an agent skill.

## Why does Prufa split AI judgment from code checks?

Trust is the hard part of AI testing. A test that an LLM says passed is not proof. Prufa's design lets the agent explore the app but leaves the pass or fail call to plain code, and it marks LLM opinions as advisory ([founder-reported, TrustMRR](https://trustmrr.com/startup/prufa)).

That split speaks to developers who have seen AI tools report confident but wrong results. The stack is conventional: Vue.js and Astro on the frontend, Python, PostgreSQL and Kubernetes on Hetzner behind it.

Our observation: securenow.ai and Prufa both sell insurance against a silent failure, and both are early. Capgo shows that developer tools wired into every release can build strong recurring revenue. Prufa's per-deploy design points the same way, but it has not yet turned into subscriptions.

## What are the lessons from Prufa so far?

- **MRR alone can mislead.** $29 MRR hides $2,846 collected in a month.
- **Make AI results checkable.** Code-verified findings answer the main doubt about AI testing.
- **A no-signup audit lowers the barrier.** Paste a URL and see results in 60 seconds.
- **Serve agents too.** A CLI, API and MCP server let AI coding agents run tests themselves.
