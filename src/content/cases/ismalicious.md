Threat intelligence is usually sold by large vendors on annual contracts. isMalicious sells it the indie way: a free lookup page, a public API and a €99 Pro plan, run by one person. In November 2026 it showed $1,628 in monthly recurring revenue and $16,339 in all-time revenue ([verified, TrustMRR](https://trustmrr.com/startup/ismalicious)). The founder posts as Hexabl0b and has 16.6k followers on X, far more than the revenue alone would suggest.

## What does isMalicious check, and who uses it?

isMalicious checks whether an indicator is known to be malicious. The homepage lists IPs, domains, URLs, emails, phone numbers, crypto wallets, file hashes, CVEs and ASNs, and shows the evidence and sources behind each verdict ([founder-reported, isMalicious homepage](https://ismalicious.com/)). The free plan includes website lookups with no monthly cap and 250 API requests a month.

The listing names SOC teams, managed security providers and developers building security products as the audience. It also offers an MCP server, so AI assistants can query the data.

> "Real-time threat intelligence for SIEM and security products." — isMalicious listing ([founder-reported, TrustMRR](https://trustmrr.com/startup/ismalicious))

## How is isMalicious built and marketed by one person?

The listing shows a bootstrapped company of one, founded in March 2025 in France. The stack is React and Next.js on the front end, with Rust, Redis and PostgreSQL behind it and Stripe for billing ([founder-reported, TrustMRR](https://trustmrr.com/startup/ismalicious)). Rust is an unusual choice for an indie SaaS and fits a product that must answer lookups fast.

Marketing runs through a blog, a newsletter, SEO, LinkedIn and X. The domain rating is only 12, so search is not yet a big channel; the founder's X following is the main asset.

Its ceiling depends on whether it can move from individual analysts to security vendors that embed the data.

## What lessons does isMalicious teach about selling security data?

- **Free lookups build trust.** Uncapped website checks let users test the data before paying ([founder-reported, isMalicious homepage](https://ismalicious.com/)).
- **Speak the buyer's standards.** STIX/TAXII and SIEM support signal that it fits existing security tools.
- **An audience is not revenue.** 16.6k X followers sit beside 13 paying subscriptions ([verified, TrustMRR](https://trustmrr.com/startup/ismalicious)).
- **Niche means higher prices.** Each security customer pays several times what a general developer tool charges.
