Resellers price things by checking what similar items actually sold for on eBay. SoldComps packages that lookup as an API and charges for it. In November 2026 it showed $25,931 in MRR but only $74,148 in all-time revenue ([verified, TrustMRR](https://trustmrr.com/startup/soldcomps)), which means one month of current revenue already equals about a third of everything it has ever earned. The founder's name is not disclosed.

## Why does SoldComps exist if eBay has its own API?

SoldComps exists because sold-listing data is hard for developers to get from eBay directly. The listing says eBay's Finding API heavily restricts sold listing access and is often unavailable to new developers ([founder-reported, TrustMRR](https://trustmrr.com/startup/soldcomps)). SoldComps fills that gap for resellers, flippers, developers, market researchers and estate sales.

The homepage keeps the product simple: one GET request with an API key, a keyword in, clean JSON out, with no OAuth, XML or pagination tokens ([founder-reported, SoldComps homepage](https://sold-comps.com/)). Each result includes sold price, shipping, currency, date, condition, seller feedback and a link, across 8 eBay marketplaces.

> "Real eBay sold prices. One API call." — SoldComps listing ([founder-reported, TrustMRR](https://trustmrr.com/startup/soldcomps))

## How does SoldComps charge for its data?

SoldComps charges per search rather than per result. Its homepage says one request is one keyword search that returns up to 240 sold listings, and it counts as one request whether it returns 10 results or 240 ([founder-reported, SoldComps homepage](https://sold-comps.com/)). Filters for category, price, condition and date narrow the set.

There is a small inconsistency worth noting. The TrustMRR description says one keyword returns up to 200 completed sales, while the homepage says up to 240. We report both because the pages differ, and the homepage is likely the newer copy. The free tier needs no credit card and issues an API key instantly, which lowers the barrier for developers who just want to test.

## What lessons does SoldComps teach about data products?

- **Sell the data a platform withholds.** SoldComps exists because eBay limits sold-listing access for new developers ([founder-reported, TrustMRR](https://trustmrr.com/startup/soldcomps)).
- **Make the API boring.** One endpoint, an API key and JSON remove the friction that blocks developers.
- **Price the call, not the row.** Charging per search keeps bills predictable for buyers.
- **Growth can be recent and steep.** MRR of $25,931 against $74,148 lifetime shows most revenue came in the last few months.
